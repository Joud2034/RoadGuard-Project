# Classical Pipeline Results

This folder contains compressed outputs and experiment files from the RoadGuard classical image-processing work. It does not contain the full image dataset.

## Contents

- `Member3_Figures_improved`: preprocessing comparisons and figures generated during Development.
- `Member4_Improved_Results`: earlier Member 4 experiment outputs, configurations, comparisons, and prediction files.
- `Member4_Improved_Results_improved`: Development checkpoints, selected configurations, validation analysis, and final Test evaluation outputs, including metrics and predictions.
- `Member4_Improved_v2_Results`: files from an alternative Member 4 version, including its settings and prediction outputs.
- `RoadGuard_Canny_Baseline_improved`: Development prediction files for the Tuned Canny Baseline.
- `RoadGuard_Member4_Masks_iou50_v4`: the selected Member 4 configuration, tuning and validation comparisons, example figures, and exploratory Sauvola results.

The archives preserve outputs from different experiment versions. For the final Test evaluation, refer to the latest run inside `Member4_Improved_Results_improved`. The other archives are retained as development or experimental records.
